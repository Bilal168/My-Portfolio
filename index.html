FINAL YEAR PROJECT — FALL-2026-51

Gesture-Based Touchless Radiology Image Interaction System

Overview

A touchless interaction system that lets doctors browse and manipulate radiology images using hand gestures alone — removing the need to touch a keyboard or mouse during procedures, improving hygiene and workflow efficiency in clinical settings.

Problem It Solves

In sterile clinical environments, doctors often need to re-scrub or use extra precautions after touching shared input devices. This system removes that friction by letting radiology images be zoomed, panned, and scrolled through hand gestures captured via camera, keeping the workflow hygienic and uninterrupted.

Key Features

  • Real-time hand gesture recognition using computer vision
  • Touchless zoom, pan, and scroll through radiology images
  • Designed for sterile, hands-free clinical workflows
  • Built as a Final Year Project — Phase 1 completed
